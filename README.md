## ❓ Frequently Asked Questions (FAQ)

### Do I need an internet connection?
**No, not for normal use.** The toolkit runs entirely on your computer. You only need internet if you want to download updates later.

### Will this work on my computer?
This version supports **Windows 10 and Windows 11** (both 64-bit). If you're on a Mac, look for the `.dmg` version on the same download page. The app uses about 2 GB of RAM and needs 5 GB of free disk space.

### Is it really free?
Yes, this is a **100% free, open-source** project. There are no hidden fees or premium tiers. The developers believe AI tools should be accessible to everyone.

### How do I know my data is safe?
All your data (notes, conversation history, tasks) is stored in a single encrypted file on your computer with a password you create during setup (optional). Nothing is ever transmitted to any external server. You can even delete the app and take your data file with you – it's yours.

### I made a mistake. How do I delete something?
In any conversation, click the **trash icon** (🗑️) next to the message you want to remove. To clear ALL data, go to **Settings → Danger Zone → Erase All Data**. Do this carefully – it cannot be undone.

## 🧰 Troubleshooting (If Something Goes Wrong)

### Problem: App won't open after download.
**Solution:** Right-click the downloaded `.exe` file. Select **"Run as administrator"**. If a blue popup appears, click "Yes". This usually fixes the issue.

### Problem: The app says "Missing component" or "DLL not found."
**Solution:** Download the latest version again from the same link. Exit any antivirus temporarily (it sometimes blocks the app's files). Then re-install. This happens rarely and is always solved by a fresh download.

### Problem: My typing is laggy or slow.
**Solution:** Close other heavy programs (like web browsers with many tabs). The app uses your computer's processor, so it needs some free resources. Also, make sure you've restarted the app after your first day of use – the first run performs background optimization.

### Problem: I lost my saved data after an update.
**Solution:** Your data file is never deleted during updates. Look for a file named `my_data.enc` in the working folder you chose during setup. Please back it up periodically by copying that single file to a USB drive.
